SURVIVAL MODE DEV INSTALL - KEY LIST (FROM 0.74.49)
Build: VALKA=1 ZFA=1 TANI=1 sh tools/package_dev.sh (test keys kept). [ZFA=1] / [TANI=1] / [VALKA=1]: that part only works
with it in the build. Every key is Ctrl+ unless said. Any test key makes that run unranked (LUA LOG "leaderboard: test
key <key> pressed: this run won't be ranked"). In co-op press them as HOST; the joiners follow your round.
The [ ] \ ; / ' keys are UE4SS's OEM_ names for a US layout (OEM_FOUR [, OEM_SIX ], OEM_FIVE \, OEM_ONE ;, OEM_TWO /,
OEM_SEVEN '): on another layout it's the key Windows calls that.
